# medsam2 instructions

- Interactive 3D medical segmentation (MRI/CT NIfTI and DICOM) with MedSAM2 (`sam2.1_hiera_t512`, `MedSAM2_latest.pt`, Apache-2.0 / CC-BY-SA-4.0) exported to four opset-17 ONNX graphs pinned in `models/medsam2.manifest.json`: `medsam2-image-encoder.onnx`, `medsam2-mask-decoder.onnx`, `medsam2-memory-encoder.onnx`, and `medsam2-memory-attention.onnx` (`validation/export_onnx.py`).
- Bidirectional 3D memory-bank propagation in `src/worker.js` and `src/segmentation.js` matches PyTorch CPU `SAM2VideoPredictor` (`build_sam2_video_predictor_npz`, bilinear 512×512 input resize, `fill_hole_area=0`), including `dynamic_multimask_via_stability(delta=0.05, thresh=0.98)` (falling back to best of tokens `1..3` for the mask while retaining token 0 for `obj_ptr`) and `binarize_mask_from_pts_for_mem_enc=true` (`is_mask_from_pts=1` on prompted conditioning frames in `medsam2-memory-encoder.onnx`); `e2e/workflow.spec.js` checks browser outputs against `validation/reference.json`.
- The workspace offers a pixel-exact 2D `Prompt` view (`#promptCanvas`) for clicking/boxing on axial, coronal or sagittal slices alongside NiiVue (`#gl1`) `3-Plane / Axial / Coronal / Sagittal / 3D` views and the shared `nd-mask-editor` on the Output segmentation row for manual voxel touch-ups. Outputs are a 3D uint8 NIfTI label map preserving input header geometry and a TSV volumetric table (`mm³` and `mL`).

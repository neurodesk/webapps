About MuscleMap

MuscleMap

Whole-body muscle segmentation in the browser

MuscleMap is a browser-based tool for automatic muscle segmentation from MRI or CT using an official MONAI 2D UNet model.

All computation runs locally in your browser using ONNX Runtime Web. Patient data is not uploaded to any server.

Privacy

Your data never leaves your device.

MuscleMap runs entirely in your web browser using WebAssembly and ONNX Runtime. All processing occurs locally on your machine.

What this means

  • Patient images, voxel values, screenshots, and generated segmentations are not uploaded to any server or cloud service
  • No internet connection is required after the page loads
  • Sensitive patient data remains on your computer at all times
  • There is no need to anonymise or de-identify your data before use

How it works

MuscleMap uses ONNX Runtime Web to run deep learning models directly in the browser via WebAssembly. Your NIfTI or DICOM files are read into browser memory, processed locally, and results are displayed without any network transfer.

Third-party services

The Neurodesk hosting layer records page views only, unless your browser sends Do Not Track or Global Privacy Control. It does not send custom events, patient images, voxel values, screenshots, generated segmentations, filenames, or analysis results to Google Analytics. Other network requests load the application itself, runtime assets, and model files, which may be cached locally.

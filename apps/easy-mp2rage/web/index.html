Workflow help

Load UNI, INV2 and a B1 source for T1 mapping. SA2RAGE must contain both GRE volumes. Denoising needs UNI, INV1 and INV2.

Check sequence parameters against your protocol before computing. JSON and DICOM metadata do not contain every required parameter.

Select View beside an output to inspect it. Use the slice sliders or the mouse wheel over each plane. Download individual maps or the complete bundle.

For BIDS, choose a dataset root and calculate each session. Download and unload a completed session before moving to the next.

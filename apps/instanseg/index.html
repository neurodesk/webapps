Input image

2D RGB brightfield histology up to 16 MP (0.5 µm/px native). iInstanSeg brightfield_nuclei segments 2D RGB brightfield histology images (H&E, DAB) in TIFF, OME-TIFF, or PNG up to 4096 × 4096 pixels. Calibrated images are resampled automatically to 0.5 µm/px and mapped back to original pixels. For whole-slide images or multiplex fluorescence, use the Standalone container.

Nucleus segmentation

Model: Brightfield nuclei (brightfield_nuclei v0.1.1).

Advanced settings

Automatic uses the GPU through WebGPU when available.

Output

Drop a 2D RGB brightfield image anywhere, or choose an example.

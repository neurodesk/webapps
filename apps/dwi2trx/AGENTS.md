# dwi2trx instructions

- WebGPU-only app (diffusion tensor fitting + GPU streamline tractography); it throws a clear error at startup on a browser without WebGPU, and streamline tracking additionally requires `subgroups` support.
- `packages/dwi2trx` and `apps/dwi2trx` pin the exact published `@niivue/niimath@1.4.20261114` release (dtifit-enabled, with the repeated-eigenvalue fix rordenlab/niimath#83, small positive eigenvalue fix rordenlab/niimath#84, and `./package.json` export rordenlab/niimath#82), which NODDI also uses. `@neurodesk/dwi2trx/niimath-version` imports `@niivue/niimath/package.json`, which DWI2TRX and NODDI write to provenance. Keep both pins in lockstep and rerecord `packages/dwi2trx/validation/dwi-gradients-reference.json` (and update `runtime-assets/manifest.json`) when changing the pin.
- `public/brainchop/` is generated by `scripts/copy-brainchop.mjs` (stages `@brainchop/core`'s WebGPU weights and worker for runtime fetch) and is gitignored — regenerate it via `dev`/`build`, don't hand-edit or commit it.
- TypeScript unit tests under `src/` run with `node --experimental-strip-types`, not a bundler.
- The Playwright e2e smoke test needs a WebGPU-capable Chromium.

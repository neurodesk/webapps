Add the BLAST-CT webapp and `@neurodesk/blastct` package for in-browser 3D non-contrast head CT traumatic brain injury lesion segmentation (IPH, EAH, perilesional oedema, and IVH) using the dynamic-shape DeepMedic v2 multi-centre model (biomedia-mira/blast-ct v2.1.0, checkpoint 1) in ONNX Runtime Web (WebGPU and threaded WebAssembly).

Add the `fireants` command line. It runs the web app's CPU registration with Node, offers the Greedy and SyN presets and writes the web app's `<moving>_registered.nii.gz`. Portable Linux x64, Windows x64 and macOS arm64 archives bundle the Node runtime. Before release, each archive must match the web app's engine, run in-process on the pinned T1-to-MNI example. MindGrab brain extraction and WebGPU stay in the web app.

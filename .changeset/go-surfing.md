Vessel Surfer is now a plain "Go surfing" footer link that opens the game at `/surf/` instead of a hidden five-tap overlay. The game drops the app shell, About, Cite, Privacy and theme controls for a single full-screen view with one menu panel. Steering uses mouse aim on desktop and a floating joystick on touch, with turn-rate smoothing, a lumen-following assist, roll levelling and automatic slowing before walls. Scores go to a global leaderboard served by a Cloudflare Worker with a D1 database, falling back to this device's best runs when it is unreachable. The brain data is now the 140 µm pial artery segmentation of Subject 02 from Bollmann et al., eLife 2022;11:e71186 (OSF doi:10.17605/OSF.IO/NR6GC), cited in the game and attribution files.

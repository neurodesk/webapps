- **Portable software x87 80-bit `dnrm2` / `dznrm2` (`#730`):** replace `BigUint` in `exes/samsrf/core/src/arithmetic/intel/mod.rs` with zero-allocation software `F80` (64-bit significand, 15-bit exponent, RNE) following MKL `AVX512_E1`'s four-lane stride accumulation order. Matches all 168/168 blind real near-midpoint probes, all 48/48 blind complex near-midpoint probes (exact pre-registered digest `5db3763f…`), all 8/8 extreme-scale probes (`2^±600`, `2^±1000`, exact pre-registered digest `20add51c…`), and all 1,200/1,200 recorded `corr` values including both previously pinned near-tie misses (`n = 36` pair 6 and `n = 75` pair 16), while removing `num-bigint` from production WebAssembly.
- **Intel nonnegative-clipped CSS (`#730`):** enable `Css_Convention: "nonnegative"` for `matlab-intel` using MATLAB's `pow`, `convolve_real`, and Intel correlation/regression kernels without altering `current` default arithmetic. Matches all 48/48 evaluations and all 12/12 full Nelder-Mead `fminsearch` fine fits bit-for-bit on both Intel Xeon 6975P-C and AMD EPYC 7763.
- **Intel single-precision BLAS and two-column QR (`#731`):** add `exes/samsrf/core/src/arithmetic/intel/single.rs` (`sdot`, `sgemv_t`, `corr`, CF profile, real `RealDesign` and complex `ComplexDesign`) and lift the `matlab-intel` single-precision refusal (preserving the universal single RC 2D and single CF Gaussian refusals).

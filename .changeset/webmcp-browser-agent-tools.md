In a browser that offers WebMCP, every app registers tools with the browser's built-in AI agent. The agent can read what the app does, load an example or ask you to choose files, run any operation and wait for its report, move and restyle the viewer, and save an output. When it needs a decision, it asks you in a dialog that says an AI agent is asking, and closing the dialog declines. Browsers without WebMCP load none of this. No browser enables WebMCP by default yet.

Add a macOS arm64 installer package for the `syncro` command line. It installs SYNcro in `/usr/local/lib/neurodesk/syncro` and the `syncro` command in `/usr/local/bin`, bundles Node and the models, and is signed with a Developer ID and notarized for release. The Standalone dialog offers it beside the Windows and Linux archives, with download, checksum, `sudo installer` and `syncro self-check` commands.

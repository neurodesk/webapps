Add portable standalone command-line packages (via `exes/node-cli`) for six microscopy apps:
`lightsheet-atlas`, `calcium-imaging`, `neuromorph`, `stitching`, `microscope-qc`, and `histo2mri`,
sharing each app's scientific core between the web application and CLI.

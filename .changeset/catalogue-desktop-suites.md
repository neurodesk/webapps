Ship one offline desktop suite per catalogue. Each suite holds exactly the apps its catalogue's host serves, under that catalogue's name, brand and landing page, with a DICOM View handoff list and a model pack limited to those apps. Neurodesk Webapps keeps its application id, name and release tag, so installed copies keep updating; it no longer carries the MSK and Microscopy apps, which move to MSK Webapps and Microscopy Webapps. Preclinical Webapps is the fourth suite. Each catalogue's landing page links its own suite once that suite has been published.

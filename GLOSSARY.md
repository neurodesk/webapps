# Neurodesk Webapps

Terms for scientific workflows and their desktop execution.

## Scientific operations

**Operation**:
A declared scientific processing or viewing action with inputs, method settings and results.

**Operation parameter**:
A named method setting whose declaration describes its accepted values and default.

## Desktop results

**Artifact**:
A scientific result or provenance file produced by an application operation. An operation contract may identify the artifact by a declared output role.

**Artifact completion**:
The successful outcome of a desktop run whose result files, provenance and required run checks have all been verified.

**Completion report**:
Evidence that a desktop run and every required check completed successfully.

**Provenance report**:
A record of an application's scientific operation and its inputs, outputs and method settings.
